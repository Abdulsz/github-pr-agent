# Frontend Skill Examples

Use these examples to quickly calibrate outputs toward restrained, premium UI work.

## 1) Landing Page Brief

### Good input brief

"Create a landing page for Aurora Studio, a boutique design agency. First screen must be full-bleed photography, with brand name dominant, short headline, and one CTA. Keep sections to: hero, one proof block, one process/story block, final CTA. No generic SaaS cards."

### Weak input brief

"Make a modern website with lots of sections, cards, icons, and cool effects."

### Expected output traits

- First viewport reads like a poster with one dominant visual anchor
- Brand is unmistakable without relying on nav
- Sparse, scannable copy with one primary action
- Section sequence is simple and non-redundant

## 2) Product Dashboard Brief

### Good input brief

"Design an operations dashboard for shipment monitoring. Prioritize utility copy and scanning speed. Layout should emphasize KPI row, filters, table, and right-side detail inspector. Use one accent color for status/actions. Avoid hero messaging."

### Weak input brief

"Make the dashboard feel inspiring with a big hero and marketing-style headline."

### Expected output traits

- Headings are operational: 'Selected KPIs', 'Plan status', 'Last sync'
- Structure favors workflow over decorative card mosaics
- Copy explains scope/freshness/decisions, not brand mood
- Visual hierarchy supports monitor -> decide -> act behavior

## 3) Motion Direction

### Good motion plan

- Hero entrance: staged fade/translate for brand, headline, CTA
- Scroll behavior: subtle depth shift on hero media as next section enters
- Interaction: restrained hover reveal on key action elements

### Weak motion plan

- Constant looping effects across many elements
- Multiple animation styles with different easings/durations
- Motion that exists only for decoration

### Expected output traits

- Motion is noticeable in a quick recording but never noisy
- Timing and easing feel consistent across sections
- Performance remains smooth on common mobile devices

## 4) Full-Bleed Hero Sanity Check

Before finalizing a branded landing page hero, verify:

- Hero container runs edge-to-edge without inherited page max-width
- Inner text/action column is constrained for readability
- Sticky/fixed header is accounted for in first-viewport budget
- Text contrast and tap targets remain clear over imagery
